# ArcadeForge AI — Design, Compile, and Play Retro Arcade Games

**ArcadeForge AI** is a mobile-first retro arcade creation studio powered by **GPT-6 Astra**. Users collaborate with AI through an iterative design conversation or mobile QR scan wizard to conceive, balance, compile, and instantly play custom 2D arcade games.

---

## Key Features

### 🕹️ Multi-Genre Arcade Engine
* **Beat 'Em Up:** Classic brawler mechanics (inspired by The Simpsons & TMNT arcade classics) with combo attacks, crowd control, and health pick-ups.
* **Dungeon Crawler & Rogue-Like:** Grid-based and real-time procedurally inspired labyrinths with enemy mobs and loot.
* **Side-Scrolling Platformer:** Precision jumps, hazards, and scrolling backgrounds.
* **Retro Shmup / Space Shooter:** Wave-based bullet patterns and power-ups.
* **Retro Board & Turn-Based Games:** Classic tabletop strategy digitized into retro pixel art.

### 📱 Mobile-First Design & QR Onboarding
* **Scan to Design:** Scan the on-screen QR code from any smartphone camera to open the mobile game design wizard.
* **Virtual Arcade Controls:** Touch-optimized on-screen directional pad and responsive Action [A] / Attack [B] buttons with haptic feedback.
* **Chiptune Audio Synthesizer:** Real-time Web Audio 8-bit sound effects and retro jingles.

### 🧠 Powered by GPT-6 Astra
* **Iterative Dialogue Studio:** Converse with GPT-6 Astra to tweak enemy speeds, add character moves, change pixel themes, and balance difficulty.
* **Dual Runtime:** Runs instantly in browser Canvas and exports complete standalone Python Pygame source code (`game.py`) for desktop execution.

---

## 🔒 Security
Protected by a client-side SHA-256 cryptographic passcode gate. API credentials and authentication secrets are not documented or stored in plaintext.
